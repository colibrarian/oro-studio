# Связка сайта с Google Календарём

Скрипт `Code.gs` живёт в Google-аккаунте **events@orostudiotallinn.com** и связывает календарь сайта с Google Календарём этого аккаунта:

- на сайте занятые дни и часы закрыты (берутся из событий календаря, названия событий наружу не уходят);
- заявка с сайта сразу ставит **жёлтое событие «Заявка: …»** в календарь и присылает письмо на events@orostudiotallinn.com;
- если бронь не состоялась, достаточно **удалить событие**, и время снова свободно на сайте;
- любое событие, которое Наталья ставит в этот календарь сама, автоматически закрывает время на сайте.

## Установка (один раз, 5–10 минут)

1. Войти в Google под **events@orostudiotallinn.com** и открыть https://script.google.com → **Новый проект**.
2. Назвать проект `ORO Studio booking`. Удалить всё в файле `Code.gs` и вставить содержимое `google-apps-script/Code.gs` из репозитория. Сохранить (Ctrl/Cmd+S).
3. Вверху выбрать функцию **testSetup** → **Выполнить**. Google попросит доступ: «Проверить разрешения» → выбрать аккаунт → «Дополнительные настройки» → «Перейти к проекту (небезопасно)» → «Разрешить». Это нормально: скрипт ваш собственный, Google просто не проверял его как публичное приложение. В журнале появится имя календаря.
4. **Развернуть → Новое развёртывание** → шестерёнка → **Веб-приложение**:
   - Описание: `v1`
   - Запуск от имени: **Я (events@orostudiotallinn.com)**
   - Доступ: **Все** (Anyone)
   - **Развернуть**.
5. Скопировать **URL веб-приложения** (заканчивается на `/exec`). Проверка: открыть его в браузере, должно показать `{"ok":true,"service":"ORO Studio booking"}`.
6. Вставить этот URL в `site.config.js` → `BOOKING_API_URL = "https://script.google.com/macros/s/.../exec";` и запушить.

## Если меняете код скрипта

Развернуть → **Управление развёртываниями** → карандаш → Версия: **Новая версия** → Развернуть. URL при этом остаётся прежним, на сайте ничего менять не нужно. (Если сделать «Новое развёртывание», URL будет новый.)

## Настройки (в начале `Code.gs`)

- `CALENDAR_ID` — `"primary"` = основной календарь аккаунта. Можно завести отдельный календарь «ORO бронирования» и вставить его ID (Настройки календаря → Интеграция календаря → Идентификатор).
- `OPEN_HOUR` / `CLOSE_HOUR` — часы работы (сейчас 10–20, как на сайте).
- `NOTIFY_EMAIL` — куда слать письма о заявках.
- `MAX_BOOKINGS_PER_HOUR` — защита от спама.

## Что важно знать

- Время студии считается по Таллинну (`Europe/Tallinn`).
- Событие на весь день (например «Выходной») закрывает весь день.
- Отклонённые приглашения время не занимают.
- Если скрипт недоступен, сайт сам переключится на отправку заявки через WhatsApp, так что заявки не теряются.
- Бесплатные лимиты Google (письма, вызовы) многократно больше, чем нужно студии.
